# Drafts

Messages and documents for other groups that we haven't sent yet. When one is sent, move it with `git mv` to `docs/groups/<date>-g5-to-<group>.md` and add a note at its top saying how it was sent, as the other records do.

A draft that announces a change to our API or our messages goes out only once the report and `openapi.yaml` say it, or a grilling record lists that edit under "For the report", where the tickets cut at the cutoff pick it up (`docs/agents/group-replies.md`). Otherwise a group can read our report and find a contract we've already promised them missing from it.
