# Drafts

Messages and documents for other groups that we haven't sent yet. When one is sent, move it with `git mv` to `docs/groups/<date>-g5-to-<group>.md` and add a note at its top saying how it was sent, as the other records do.

A draft that announces a change to our API or our messages goes out only once the report and `openapi.yaml` say it, or an open issue tracks that edit. Otherwise a group can read our report and find a contract we've already promised them missing from it.

- `g5-to-g3-rebooking.md`: a WhatsApp message to G3 about Rebooking. Send it once an open issue tracks the report's Rebooking edits, and paste it from below its note.
- `g5-to-g4.md`: a document in the layout G3 used for us (`../2026-11-16-g3-to-g5.md`). Share it as a file, and send G4's representative its link with:

> Hi, Group 5 (Places) here. We wrote a short document with what we need from your group, what we send you, and some questions: <link>. You can comment on it or answer here.
