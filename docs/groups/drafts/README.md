# Drafts

Messages and documents for other groups that we haven't sent yet. When one is sent, move it with `git mv` to `docs/groups/<date>-g5-to-<group>.md` and add a note at its top saying how it was sent, as the other records do.

A draft that announces a change to our API or our messages goes out only once the report and `openapi.yaml` say it, or a grilling record lists that edit under "For the report", where the tickets cut at the cutoff pick it up (`docs/agents/group-replies.md`). Otherwise a group can read our report and find a contract we've already promised them missing from it.

- `g5-to-g3-rebooking.md`: a WhatsApp message to G3 about Rebooking. Its report edits are listed in `docs/grilling/2026-11-16-g2-report.md`, so it can go now. Paste it from below its note.
- `g5-to-g1-batch.md`: a WhatsApp message to G1 saying we prefer their batch call to a queue. It changes nothing in our API, so it can go now, and should, while G1's group is still deciding. Paste it from below its note.
- `g5-to-g4.md`: a document in the layout G3 used for us (`../2026-11-16-g3-to-g5.md`). Share it as a file, and send G4's representative its link with:

> Hi, Group 5 (Places) here. We wrote a short document with what we need from your group, what we send you, and some questions: <link>. You can comment on it or answer here.
