# Drafts

Messages and documents for other groups that we haven't sent yet. When one is sent, move it with `git mv` to `docs/groups/<date>-g5-to-<group>.md` and add a note at its top saying how it was sent, as the other records do.

- `g5-to-all.md`: a WhatsApp message to every group. Paste it from below its note.
- `g5-to-g2.md` and `g5-to-g4.md`: documents in the layout G3 used for us (`../2026-11-16-g3-to-g5.md`). Share each as a file, and send the group's representative its link with:

> Hi, Group 5 (Places) here. We wrote a short document with what we need from your group, what we send you, and some questions: <link>. You can comment on it or answer here.
